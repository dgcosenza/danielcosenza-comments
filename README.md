Public GitHub Discussions repository powering [giscus](https://giscus.app/) reader comments for [danielcosenza.com](https://danielcosenza.com/), maintained by **Daniel G. Cosenza from FNX Labs**.

## Purpose

- Hosts public comment threads backed by GitHub Discussions for articles published on `danielcosenza.com`.
- Automated weekly and push/PR security checks (`.github/workflows/security.yml`) enforce commit-SHA action pinning, full-history Gitleaks secret scanning, and Zizmor workflow auditing.

## Security

Please report security concerns privately via [GitHub Security Advisories](https://github.com/dgcosenza/danielcosenza-comments/security/advisories/new).
